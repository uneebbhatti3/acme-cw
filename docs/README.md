# Project Docs

Specification for the surgical instruments manufacturer demo site. Read in this order:

| #   | File                                               | What it covers                                        |
| --- | -------------------------------------------------- | ----------------------------------------------------- |
| 1   | [PROJECT_BRIEF.md](PROJECT_BRIEF.md)               | Goals, audience, scope, what the demo must and must not do |
| 2   | [SITEMAP_AND_PAGES.md](SITEMAP_AND_PAGES.md)       | Every page and every section on it                    |
| 3   | [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)               | Colour, type, spacing, motion, imagery rules          |
| 4   | [COMPONENTS.md](COMPONENTS.md)                     | Component behaviour, especially the product gallery   |
| 5   | [CONTENT_PLACEHOLDERS.md](CONTENT_PLACEHOLDERS.md) | Data types and sample data                            |
| 6   | [TECH_SPEC.md](TECH_SPEC.md)                       | Stack, folder structure, performance, SEO, a11y       |
| 7   | [BUILD_PLAN.md](BUILD_PLAN.md)                     | Phased plan with acceptance checks                    |

`DECISIONS.md` is created here during the build to log judgement calls.

Agent instructions live at the repo root in `CLAUDE.md` and `AGENTS.md`.
